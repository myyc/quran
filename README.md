# Quran

Offline Quran reader for Android, built with Flutter. Black + green, flat UI.

- Three reading modes: continuous flow, verses, Arabic + translation
- Four translations, Ibn Kathir tafsir, full-text search
- Bookmarks, notes, reading position, per-surah progress, backup/export

```sh
flutter pub get && flutter build apk --release
```

Text: Tanzil/AlQuran Cloud · Tafsir: spa5k/tafsir_api · Fonts: Inter, Amiri, Reem Kufi
